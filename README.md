# Nelya

Nelya est un projet d'IA conversationnelle entraînée progressivement.

## Version actuelle

**V0.1.1**

Le versionnage progresse ainsi :

`V0.1.1 → V0.1.2 → ... → V0.1.9 → V0.2.0 → ... → V1.0.0`

**V1.0.0** correspondra à la première version publique de Nelya.

## Objectif

Construire progressivement une IA capable de tenir un véritable échange conversationnel, avec des phases régulières d'entraînement, de test et de sauvegarde.

## Entraînement

Les données seront traitées progressivement, avec un test prévu environ tous les **20 000 exemples**.

Objectif initial : **500 000 exemples minimum** avant d'évaluer la suite du développement.

## Projet

Le dépôt accueillera :
- l'interface web de discussion ;
- les outils de préparation des données ;
- le suivi des versions et tests ;
- les fichiers nécessaires à l'entraînement ;
- les sauvegardes et checkpoints référencés séparément lorsque leur taille le nécessite.
